# 분류별·정액 할인 프로모션 지원

## 업무 요청

기존 쿠폰을 유지하면서 특정 분류에 적용되는 할인과 정액 할인 행사를 추가하려고 합니다.
고객이 적용된 할인과 최종 금액을 견적·주문에서 이해할 수 있어야 합니다.

## Pair 시작 질문

> 기존 쿠폰 동작을 유지하면서 분류별 할인과 정액 할인을 지원하고 싶어.
> 현재 가격 계산을 같이 살펴보면서 어디부터 접근할지 이야기해 보자.
> 아직 구체적인 구현 방법은 정하지 않았어.

## 빠른 시작

루트에서 `MARKETLANE_DB=.data/promotion-rules.sqlite npm run dev`를 실행합니다.
main의 기본 DB나 다른 과제와 DB를 공유하지 마세요.
브랜치 전환·초기화 전 서버를 중지합니다. 필요할 때만 초기화하세요:
`MARKETLANE_DB=.data/promotion-rules.sqlite npm run db:reset -- --confirm`

## 수용 기준

1. 기존 WELCOME10의 적용 조건, 할인액, 배송비와 오류 동작을 유지합니다.
2. DESK15는 할인 전 desk 상품 금액이 5,000 cents 이상이면 desk 상품만 15% 할인합니다.
   Carry·paper는 할인 대상이나 자격 금액에 포함하지 않습니다.
3. TAKE1200은 최소 금액 조건 없이 상품 금액에서 최대 1,200 cents를 할인합니다.
   상품 금액보다 많이 할인하거나 배송비를 할인하지 않습니다.
4. 항목별 할인과 합계가 정확히 맞고 모든 금액은 음수가 아닌 정수 USD cents입니다.
   할인 귀속과 반올림의 업무 규칙은 사용자와 정해 설명하며, 상품을 담은 순서만으로
   동일한 장바구니의 할인 결과가 바뀌지 않습니다.
5. 복수 쿠폰의 허용 여부와 조건을 명확히 정해 안내합니다. 지원하지 않는 조합은
   이유를 알리고, 쿠폰 일부를 조용히 무시하거나 의도하지 않은 중복 할인을 하지 않습니다.
6. 할인 후 상품 금액이 10,000 cents 미만이면 배송비는 590 cents, 이상이면 0입니다.
   상품 금액이 전액 할인되어도 기존 배송비 규칙은 유지합니다.
7. 견적과 주문에서 같은 할인 규칙이 적용됩니다. 주문 접수 시 현재 가격·재고를
   반영하며, 화면에서 적용된 할인·자격 오류와 최종 금액을 확인할 수 있습니다.
8. 접수된 주문의 할인 이유와 금액을 나중에도 확인할 수 있습니다. 상품이나 행사 정의가
   바뀌어도 기존 WELCOME10 주문을 포함한 과거 주문의 금액은 바뀌지 않습니다.

## 범위

USD 할인 행사만 다룹니다. 세금, 환율 변환, 실제 결제, 예약 실행이나 프로모션 관리
콘솔은 포함하지 않습니다. 할인 계산 알고리즘, 규칙 표현과 저장 구조는 정하지 않습니다.
